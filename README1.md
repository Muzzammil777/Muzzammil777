## ◈ Featured Projects

<details>
<summary><strong>🛡️ Wildlife Intrusion Prevention System</strong> — AI-Powered Perimeter Intelligence</summary>

<br/>

An autonomous wildlife intrusion detection and deterrence platform combining aerial drone surveillance with ground-level ultrasonic sensor arrays. YOLOv8 processes real-time video feeds to classify animal species and trigger context-aware deterrent responses. The system operates at the hardware-software boundary with sub-second detection latency on resource-constrained edge devices.

<div align="center">

| Attribute | Details |
|---|---|
| **Stack** | Python · FastAPI · YOLOv8 · ESP32 · DroneKit · GPS · IoT |
| **Scale** | Real-time multi-zone perimeter coverage with aerial + ground sensor fusion |
| **Performance** | Sub-second inference on edge hardware via optimized YOLOv8 model pipeline |
| **Security** | Encrypted telemetry channels · sensor tamper detection |
| **Impact** | Active prototype — government-acknowledged innovation in precision agriculture defense |
| **Repository** | [github.com/Muzzammil777](https://github.com/Muzzammil777) |

</div>

The architecture decouples detection, classification, and response into discrete FastAPI microservices, enabling independent scaling and hardware-agnostic sensor plug-in. DroneKit handles autonomous flight path computation while GPS telemetry feeds back into the central dashboard for incident logging and zone management.

</details>

<details>
<summary><strong>🚁 Drone Management System</strong> — Autonomous Mission Intelligence Platform</summary>

<br/>

A full-stack intelligent drone fleet management platform enabling operators to plan, dispatch, and monitor autonomous drone missions through a live geospatial interface. The system integrates AI-driven route optimization and natural language mission planning via the Groq API, with all real-time position data rendered on a Google Maps canvas.

<div align="center">

| Attribute | Details |
|---|---|
| **Stack** | Python · FastAPI · React · MongoDB · Google Maps API · Groq API |
| **Scale** | Multi-drone concurrent mission tracking with live telemetry aggregation |
| **Performance** | Streaming websocket telemetry updates with <200ms dashboard refresh |
| **Security** | Role-based access control · API key vault · audit trail on all mission events |
| **Impact** | Reduced manual mission planning overhead by enabling AI-assisted route generation |
| **Repository** | [github.com/Muzzammil777](https://github.com/Muzzammil777) |

</div>

The backend follows a clean service-repository pattern with FastAPI routers segregating mission, fleet, and telemetry domains. MongoDB Atlas stores mission state as document collections, enabling rapid iteration on schema as product requirements evolved. The React frontend uses a component-driven architecture with dedicated hooks for real-time socket state management.

</details>

---

<details>
<summary><strong>⚖️ AI-Powered Grievance Portal</strong> — Semantic Routing Engine</summary>

<br/>

An intelligent public grievance management system that eliminates manual triaging by using semantic embedding models to classify and route petitions to the correct government department in real time. RAG architecture enables the system to reason over a policy document corpus when assigning routing confidence scores.

<div align="center">

| Attribute | Details |
|---|---|
| **Stack** | FastAPI · MongoDB · Groq API · RAG · Sentence Transformers |
| **Scale** | Handles concurrent petition intake with async processing pipeline |
| **Performance** | <500ms end-to-end classification and routing per petition |
| **Security** | Input sanitization · submission rate limiting · audit log of all routing decisions |
| **Impact** | Eliminates manual classification bottleneck — automated routing accuracy >90% in testing |
| **Repository** | [github.com/Muzzammil777](https://github.com/Muzzammil777) |

</div>

The core classification engine vectorizes petition text using a fine-tuned embedding model, retrieves semantically similar policy documents from a MongoDB vector store, and passes retrieved context alongside the petition to the Groq LLM for final department assignment. The FastAPI layer exposes async endpoints for high-throughput intake without blocking on inference.

</details>
